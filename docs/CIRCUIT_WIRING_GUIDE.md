## 1. ตารางสรุปการเชื่อมต่อขา ESP32 DevKit

| ขา ESP32 (GPIO) | อุปกรณ์ที่เชื่อมต่อ | ขาบนตัวโมดูล | ชนิดสัญญาณ | แรงดันไฟ | ข้อควรระวัง / คำแนะนำในการต่อ |
| :---: | :--- | :---: | :---: | :---: | :--- |
| **GPIO 32** | **DHT11** (เซนเซอร์วัดอุณหภูมิ/ความชื้น) | DATA / OUT | Digital I/O | 3.3V หรือ 5V | หากใช้โมดูลแบบไม่มีบอร์ดสำเร็จรูป ควรต่อ Pull-up $4.7\text{k}\Omega - 10\text{k}\Omega$ ระหว่าง VCC กับ DATA |
| **GPIO 33** | **PIR HC-SR501** (ตรวจจับความเคลื่อนไหว) | OUT | Digital Input | เลี้ยงไฟ 5V (OUT = 3.3V) | ไฟเลี้ยงโมดูลต้องต่อ **5V (VIN)** แต่ขาสัญญาณ OUT จะส่ง 3.3V เข้า ESP32 ได้โดยตรง |
| **GPIO 26** | **LED ไฟห้องจำลอง** (Room Light) | Anode (+) | Digital Output | 3.3V | **ต้องต่อตัวต้านทาน $220\Omega$ คั่น** ก่อนเข้าขาบวกของ LED, ขาลบต่อ GND |
| **GPIO 18** | **LED แสดงผลตรวจจับ PIR** (Motion Status) | Anode (+) | Digital Output | 3.3V | **ต้องต่อตัวต้านทาน $220\Omega$ คั่น** ก่อนเข้าขาบวกของ LED, ขาลบต่อ GND |
| **GPIO 25** | **เซอร์โวมอเตอร์ SG92R** (ประตูจำลอง) | Signal (สีส้ม/เหลือง) | PWM Output | สัญญาณ 3.3V (ไฟเลี้ยง 5V แยก) | ⚠️ **ห้ามดึงไฟเลี้ยงจาก ESP32** ให้ใช้ไฟ 5V จากแหล่งจ่ายแยก และต้องเชื่อม **GND ร่วมกับ ESP32** |
| **GPIO 19** | **DAC PCM5102** (I2S Audio Decoder) | **BCK / BCLK** (Bit Clock) | I2S Clock | 3.3V | สัญญาณนาฬิกาบิตข้อมูลเสียงระบบดิจิทัล |
| **GPIO 21** | **DAC PCM5102** (I2S Audio Decoder) | **LCK / LRCK** (Word Select) | I2S Left/Right | 3.3V | สลับช่องสัญญาณเสียงซ้าย-ขวา (Left/Right Clock) |
| **GPIO 22** | **DAC PCM5102** (I2S Audio Decoder) | **DIN / DATA** (Serial Data) | I2S Data Stream | 3.3V | สตรีมข้อมูลเสียงดิจิทัลความละเอียดสูง |
| **GND** | **กราวด์ร่วม (Common Ground)** | GND ทั้งหมด | Ground 0V | 0V | **สำคัญที่สุด**: ต้องต่อ GND ของ ESP32, เซอร์โว, PCM5102, LED และเซนเซอร์ทั้งหมดถึงกัน |
| **VIN (5V)** | **รับไฟเลี้ยงระบบ** | แหล่งจ่ายไฟ 5V | Power In | 5V DC (2A - 3A) | จ่ายไฟให้บอร์ด ESP32, ไฟเลี้ยงโมดูล PIR HC-SR501 |

## 2. แผนภาพผังวงจร (ESP32 DevKit Wiring Diagram)

```text
                                  ┌──────────────────────────┐
                                  │     ESP32 DEVKIT V1      │
                                  │                          │
(Motion Status LED)               │GPIO 18 [PIR STATUS LED]  │===> [R 220Ω] ===> (LED แสดงผล PIR) ===> GND
(I2S Audio Bit Clock)             │GPIO 19 [I2S BCK/BCLK]    │===> ขา BCK ของโมดูล DAC PCM5102
(I2S Audio Word Select)           │GPIO 21 [I2S LCK/LRCK]    │===> ขา LCK ของโมดูล DAC PCM5102
(I2S Audio Serial Data)           │GPIO 22 [I2S DIN/DATA]    │===> ขา DIN ของโมดูล DAC PCM5102
(Door Servo PWM Control)          │GPIO 25 [SERVO PWM]       │===> สายสัญญาณสีส้ม ของเซอร์โว SG92R
(Room Simulation Light)           │GPIO 26 [ROOM LIGHT LED]  │===> [R 220Ω] ===> (LED ไฟห้อง) ===> GND
(Room Temperature & Humidity)     │GPIO 32 [DHT11 DATA]      │<=== ขา DATA ของเซนเซอร์ DHT11
(PIR Motion Detect Input)         │GPIO 33 [PIR SENSOR OUT]  │<=== ขา OUT ของโมดูล PIR HC-SR501
                                  │                          │
(Common Ground)                   │GND                       │<===> กราวด์ร่วม (ESP32 + เซอร์โว + DAC + เซนเซอร์)
(Main 5V Supply)                  │VIN (5V)                  │<=== รับไฟ 5V จากอะแดปเตอร์ / แหล่งจ่ายไฟ
                                  └──────────────────────────┘

  [ แหล่งจ่ายไฟเซอร์โว 5V แยก ] ──(+)──> ขา VCC (สายสีแดง) ของ SG92R
                               └──(-)──> เชื่อมเข้า GND ร่วมของ ESP32

  [ เอาต์พุตเสียง PCM5102 3.5mm / RCA ] ────> ลำโพงแบบมีภาคขยาย (Active Speaker / Amplifier)
```

## 3. หลักการทำงานของระบบ (System Operation Summary)

1. **การตรวจวัดสภาพแวดล้อมภายในห้อง (Environmental Sensing)**:
   - เซนเซอร์ **DHT11 (GPIO 32)** ส่งค่าอุณหภูมิและความชื้นสัมพัทธ์แบบดิจิทัลให้ ESP32 สตรีมขึ้น Firebase Realtime Database แสดงผลบนหน้าจอ Gauge ในแดชบอร์ด
   - เซนเซอร์ **PIR HC-SR501 (GPIO 33)** ตรวจจับรังสีอินฟราเรดจากการเคลื่อนไหวของมนุษย์ เมื่อตรวจพบจะส่งสัญญาณ HIGH (3.3V) สั่งให้ **LED แสดงสถานะ (GPIO 18)** ติดสว่างทันที พร้อมสั่งเปิด **LED ไฟห้อง (GPIO 26)** อัตโนมัติ

2. **การสั่งการประตูจำลองด้วยเซอร์โว (Servo Door & Software Lock)**:
   - เซอร์โว **SG92R (GPIO 25)** ทำหน้าที่หมุนเปิด-ปิดประตูจำลอง ($0^\circ - 90^\circ / 180^\circ$)
   - **ระบบล็อก/ปลดล็อก (Software Lock Logic)**: เป็นการล็อกเชิงตรรกะในซอฟต์แวร์ เมื่อสถานะเป็น `LOCKED` บอร์ด ESP32 จะปฏิเสธคำสั่งเปิด-ปิดประตูทางไกล เพื่อความปลอดภัย จนกว่าจะมีการกดปลดล็อก (`UNLOCKED`) ผ่านแดชบอร์ด

3. **ระบบขับเสียงดิจิทัลความละเอียดสูง (Hi-Fi Digital Audio Engine)**:
   - ชิป **DAC PCM5102 (I2S บน GPIO 19, 21, 22)** รับสตรีมข้อมูลเสียงแบบ I2S จาก ESP32 แปลงเป็นสัญญาณแอนะล็อกสเตอริโอคุณภาพสูงเพื่อส่งต่อไปยังลำโพงที่มีภาคขยาย สำหรับส่งเสียงแจ้งเตือนภัยหรือข้อความเสียงพูดภาษาไทย

## 4. ข้อควรระวังทางวิศวกรรมไฟฟ้า (Engineering Best Practices)

1. **แหล่งจ่ายไฟเซอร์โว (Servo External Power)**: 
   - เซอร์โว SG92R ขณะเริ่มหมุนหรือรับแรงต้านจะดึงกระแสกระชาก (Stall Current) สูงถึง 500mA - 800mA 
   - หากต่อไฟเลี้ยงจากขา 3.3V หรือ 5V ของ ESP32 โดยตรง อาจทำให้ชิป ESP32 เกิดอาการไฟตก (Brownout Reset) และรีสตาร์ตตัวเองได้ จึงควรใช้แหล่งจ่ายไฟ 5V แยกสำหรับเซอร์โวและเชื่อมกราวด์ (GND) เข้าด้วยกัน
2. **โมดูล PCM5102**:
   - PCM5102 ทำหน้าที่เป็น DAC แปลงสัญญาณ ไม่มี IC ขยายกำลังในตัว (No Built-in Power Amp) จึงไม่ควรนำไปต่อขับดอกลำโพงเปล่าโดยตรง ต้องต่อเข้ากับลำโพงคอมพิวเตอร์, หูฟัง, หรือแอมป์ขยายเสียง (เช่น PAM8403 / PAM8406)
3. **PIR HC-SR501 Power vs Signal**:
   - ขา VCC ของ PIR ต้องต่อไฟ **5V** (เนื่องจากมี IC Regulator 7133 อยู่บนบอร์ดของมัน)
   - ขา OUT ของ PIR จะเป็นลอจิก **3.3V** เสมอ ทำให้ปลอดภัยในการต่อตรงเข้า GPIO 33 ของ ESP32 ได้ 100%
